# /male-batch

## 用途

批量创作男频小说多章。每章自动执行完整 Agent 链，章间停下等待用户审阅。

## 使用场景

- 高自动批量模式
- 一次性创作连续 3-5 章
- 使用方式：`/male-batch 3`（创作 3 章）

## 输入格式

- 起始章号
- 批量章数（建议 ≤5）
- 每章目标描述（可选，不提供则由 Chapter Planner 自动续写）

## 多 Agent 调用顺序

每章独立执行 `/male-chapter` 完整 Agent 链。
章间自动传递上下文（上一章的章末钩子、人物状态、伏笔）。

## 输出文件

- 每章独立输出（同 `/male-chapter`）
- 批量进度报告
- 批量 Agent Trace 索引

## 自动检查

- 每章独立评分 ≥ 85
- 章间连续性检查
- 章间钩子衔接检查

## 失败处理

- 单章失败 → 停止批量，报告用户
- 章间连续性断裂 → 回修上一章或调整本章

## Agent Trace 要求

每章独立 Trace + 批量总 Trace。
