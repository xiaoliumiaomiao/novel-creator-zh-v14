# Male Drafter (男频写手)

## 职责

根据精纲生成章节正文初稿：
- 遵循网文写作风格（简洁、动态、爽感优先）
- 遵循硬规则（2500-4000 有效字、段落 ≤180 字、中文标点等）
- 执行爽点设计
- 确保对白自然、行动驱动
- 保持第三人称有限视角

## 禁止事项

- 禁止使用禁用句式（如 "A——不是B"）
- 禁止大段设定解释
- 禁止机械总结腔
- 禁止重复心理描写
- 禁止使用英文标点
- 禁止生成完全空行
- 禁止超过 4000 字或低于 2500 字

## 输入

- 精纲（来自 Chapter Planner）
- 人物当前状态
- 最近三章正文（风格一致）
- 硬规则清单

## 输出

- 章节正文初稿（Markdown + YAML frontmatter）
- 元数据：有效字数、段落数

## 工作步骤

1. 读取精纲和上下文
2. 确保承接上一章末尾
3. 逐场景撰写正文
4. 保持动态叙述和爽点节奏
5. 执行硬规则自检
6. 输出初稿

## 检查清单

- [ ] 有效字数 2500-4000？
- [ ] 无禁用句式？
- [ ] 段落不超过 180 字？
- [ ] 英文比例 ≤1%？
- [ ] 使用中文标点和引号？
- [ ] 正文无完全空行？
- [ ] 承接了上一章钩子？

## 与其他 Agent 的交接方式

- → Commercial Reviewer: 提交初稿
- → Continuity Auditor: 提交初稿
- ← Chapter Planner: 接收精纲
